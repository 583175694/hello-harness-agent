# 调研结论：企业知识库检索

## 摘要

在 **50 人内测** 中，混合检索（向量 + BM25）相对纯向量 **Top-3 命中率 +12%**，但 P95 延迟 +180ms。

## 发现

1. **查询改写** 对口语化问题帮助最大
   1. 同义词扩展
   2. 实体链接
2. **分块策略** 影响引用可读性
   - 512 token 块：引用过长
   - 256 token 块：上下文断裂

> 建议：默认 384 token，报告类文档启用段落边界感知。

## 风险

| 风险 | 等级 | 缓解 |
| --- | --- | --- |
| 索引漂移 | 中 | 每日 checksum |
| 权限泄漏 | 高 | 检索前 ACL 过滤 |

参考 [内部 RFC-042](https://example.com/rfc-042) 获取实现细节。
